② 已实现功能
====================================================================
（增量修改，不要重复造轮子）
- Gradio 五个标签页：录入 / 识别 / 视频识别 / 视频实时识别 / 管理。
  - 录入：批量录入为生成器 + gr.Progress 进度条（逐类录入、逐类落盘）；结果区左右布局（左=批量录入结果，右=当前已注册列表，文字居中），列表 3 秒自动刷新；管理页删除全部/删空后同步清空录入页结果。
  - 视频实时识别：摄像头常开预览；「这是什么」触发 3 秒倒计时 → 30 帧投票识别（50ms Timer 主循环）；排行榜容器内显示「识别结果/相似度」；识别结束后按结果显示「学习」（unknown）或「纠错」（已有答案）按钮，面板展示本轮取景框 ROI 干净帧（图片名=该帧识别结果），多选 + 输入物品名 → enroll_paths_chunked 分批入库（一轮可多次录入）；点「这是什么」/开关摄像头/切 Tab 自动收起面板。
  - 特征库并发：RecognitionService.gallery_lock（threading.Lock）保护所有 gallery add/save/delete/load；3 秒热加载 Timer（录入/视频/实时/管理页均有）与录入/删除互斥，修复了"批量录入中途被 load() 覆盖只剩一个类别"的竞态。
- 识别：整图直接走 ResNet50 特征检索（top-k + 阈值判 unknown）。已移除 Faster R-CNN 检测/裁剪/画框；命令行与摄像头同样整图识别。
- 视频：抽帧后逐帧对整张帧识别 + 多数投票聚合。
- 摄像头实时识别：python webcam_app.py（按 q 退出）。
- 命令行闭环：python app_cli.py enroll / recognize / list / delete。
- 语音：Web 界面用浏览器 Web Speech API 播报（语速可调、可关闭；类别名已是中文直接朗读，原 label_zh 英中映射已删除，仅保留 unknown_label_zh 配置 unknown 播报文本）；utils/tts.py 是 pyttsx3 备用模块（python utils/tts.py 自测），仅 CLI/备用，Web 界面不依赖它；pyttsx3 为可选依赖（requirements.txt 已注释），未安装时自动降级为文本打印。
- 骨干确认：ResNet50（ImageNet1K_V1，去 FC，2048 维，L2 归一化），硬编码在 core/feature_extractor.py；预处理 Resize(256) + CenterCrop(224) + ImageNet mean/std。

③ 技术约束
====================================================================
- CPU 可运行，低算力优先；统一用项目 venv 运行（venv\Scripts\python.exe）。
- requirements.txt 钉死 torch==2.2.2 / torchvision==0.17.2 / numpy<2，不要升级 torch（系统 Python 的高版本 torch 因 DLL 初始化失败不可用）。
- PyTorch + torchvision；ImageNet 预训练 ResNet50 去掉 FC，2048 维特征，L2 归一化。
- 识别用余弦相似度 + top-k 检索；相似度低于阈值判 unknown（threshold: 0.75、topk: 5，均从 config.yaml 读取）。
- 评估参考目标 registered_acc 0.90 / unknown_recall 0.90（config.yaml 的 eval_min_*）：仅为参考目标，不是硬性要求；脚本只输出指标、不自动判定通过/失败，需人工对照。禁止为达标而调低测试门槛。
- 界面用 Gradio；语音输入与播报可降级；自动测试不依赖麦克风、摄像头、网络。
- 每次只修改我指定的文件，不改无关文件；不伪造运行结果；先给计划、再给代码、再给测试命令；测试失败只修相关文件并解释原因。

====================================================================
⑥ 关键结论与停止规则
====================================================================
- 瓶颈定位：特征判别力，非阈值 / 非预处理 / 非聚合（三者均已实验证伪）。核心表现：花卉类图与 花/白萝卜/葡萄 在 ResNet50 特征空间中重叠。
- 扩类代价：每加一类会划走一块特征空间，unknown 边界随之收缩。花类救了 flawer（0.8664 正确识别）但引入 4 张花卉类误接受（0.7564~0.8110），净收益为负。
- 证伪记录：unknown_recall 1.0 曾是 2 张小样本假象；unknown 扩到 9 张难例后暴露真实水平 0.5556（5/9）。此条供报告/答辩使用。
- 停止规则：连续 3 个不同方向都无可行区间 → 停止参数侧优化，转骨干升级 / 数据治理 / 接受现状三选一。（当前阈值、预处理、聚合三方向均已证伪，条件已满足。）
- 测试门槛规则：门槛只许随骨干/数据升级而上调，不许为让测试变绿而下调；若真实水平低于门槛，登记为已知基线失败（见 ④ pytest 失败 4/5），不掩盖。
